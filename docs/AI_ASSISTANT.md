# AI 助手：配置与执行边界

助手负责授权范围内的知识问答与只读业务查询，不负责控制设备、修改数据或诊断生产故障。

## 配置

复制 `.env.ai.example` 为 `.env.ai`，在本地填写 DeepSeek 模型配置。向量检索另需 embeddings API 的完整 HTTPS 地址、模型名和密钥；聊天模型与向量模型是两项独立服务。

模型名称以账户实际可用配置为准。更新后执行 `docker compose up -d --force-recreate backend`。密钥只由后端读取，不写入前端，也不提交到仓库。模型调用可能收费。

未配置向量服务时仍可本地词法检索；未配置问答服务时不伪造模型回答。页面上的“已配置”仅表示配置存在，不能证明余额、网络或接口可用。

## 数据与检索

1. 工程师或管理员在授权工厂下新建知识文档。
2. 文档被分块并记录版本；明确允许外发时才调用向量服务。
3. 查询在授权文档中执行 BM25/词法检索，可选融合向量排名；向量故障时注明降级。
4. 文档与向量保存在 PostgreSQL，应用进程计算余弦相似度，不是 pgvector 或 ANN 索引。
5. 文档更新/删除后，新问答复核文档版本；更换向量模型需要重新向量化，不混用不同模型空间。

当前知识库每工厂最多 100 篇文档、每篇 30,000 字符。相似度阈值是可配置检索规则，不是正确概率，也没有大规模知识库性能保证。

## 七个只读工具

| 工具 | 作用与限制 |
| --- | --- |
| `find_tags` | 按名称/编码寻找最多 20 个测点；歧义时需澄清 |
| `latest_value` | 指定测点最新值、时间、质量和过期状态；区分文件与采集来源 |
| `list_import_batches` | 最近 1—10 个批次；未完成计数不当作最终结果 |
| `inspect_import_batch` | 指定批次统计与最多 10 条问题示例 |
| `acquisition_status` | 最多 20 个采集任务的启停意图、连接、心跳和累计计数 |
| `tag_trend` | 最近 1—24 整数小时、最多 1,000 条样本的整体摘要，不做小时聚合 |
| `asset_overview` | 全量资产数量与最多 30 台设备的分配明细 |

权限、类型与参数校验由后端执行；不信任模型给出的工厂范围。显式不支持的趋势范围不会偷偷替换为较短范围。累计错误数不等于当前故障，OPC UA 连接正常也不能替代样本时间与写入计数检查。

## 回答与验收

模型响应经结构校验、工具证据检查、引用与版本复核后返回，展示来源和用量。审计不记录问题原文。引用 ID 存在不等于推论正确，需要人工核对证据是否支持结论。

验证时覆盖：不同工厂权限、文档改版和删除、无证据拒答、歧义测点、权限撤销、错误 JSON、超时、伪造引用、提示注入及不支持的时间范围。

普通 pytest 隔离真实密钥并跳过付费联调。真实评测脚本需要显式允许收费，必须使用合成资料及独立测试库。新预留集第一次执行可作为独立检查；参与调参后只能称回归。详情见 VERIFICATION.md。

当前没有通用语义正确性判定、长期对话记忆或生产级可用性承诺。
