## 如何复现

- 后端：完成数据库与邮件服务启动后，在根目录运行 `bash scripts/test-local.sh`。
- 入口安全：`uv run python -m unittest discover -s scripts/tests -v`，不访问数据库。
- 静态：`uv run prek run --all-files`。
- 页面：在临时 Compose 环境运行 Playwright 工作流，不对日常业务库运行整套浏览器测试。
- 导入性能：阅读 `backend/scripts/benchmark-import-jobs.sh` 的专用测试库与全新输出目录要求。
- 查询性能：使用 `backend/scripts/benchmark-latest.sh`，先检查脚本的测试库保护及参数。

性能实验不要和构建、备份或其他压测并行；记录完整样本，不只挑最佳结果。
